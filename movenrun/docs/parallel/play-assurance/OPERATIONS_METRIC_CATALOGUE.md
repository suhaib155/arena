## 3. Privacy rules for collection
- Record counts, ratios and sizes only. Never paste IDs, session identifiers, emails, wallet addresses, route cells or coordinates into notes, issues or screenshots; render and server logs are designed to be shareable for that reason (FREE_HOSTING_READINESS.md "Logs never contain tokens..." @ 2326aa6).
- Small-count caution: when a daily count is under 5 for a rare reason, report "under 5" rather than a list.
- Do not add new log fields containing user identifiers when implementing the NEEDS CODE rows.
