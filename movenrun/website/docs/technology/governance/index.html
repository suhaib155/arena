Governance & the DAO

MovenRun is designed to be owned by the people who move on it. It is not close. One account currently controls every deployed contract.

Where control sits today

One externally owned account holds DEFAULT_ADMIN_ROLE on all eight contracts deployed to Base Sepolia. The same account is the oracle operator, the keeper, and the treasury address. There is no separation of duties on this deployment, and no delay on anything: a timelock has been written but no timelock contract is deployed, so an admin action takes effect the moment it is sent.

That is the single largest gap between what MovenRun intends to be and what it is. Everything below describes the design that is meant to replace it.

How governance is designed to work

  1. Propose. Stakeholders put forward changes to parameters, the treasury, or the protocol.
  2. Vote. Voting power comes from a governance snapshot, so it cannot be gamed by shuffling tokens between addresses.
  3. Timelock. A passed proposal waits out a delay before it can execute, giving everyone else time to look at it.
  4. Execute. After the delay the change goes through onchain.

The community treasury

The design puts a treasury in the vault contract for governance to direct, funding growth, rewards, partnerships, and development, with allocation visible onchain. The treasury address on the current deployment is the same account that holds every admin role, so none of that accountability exists yet.

Progressive decentralization

Handing over control safely takes time, and starting from one key is normal for a project at this stage. Saying so is the point. The order of work is roughly: deploy the timelock, move admin behind it, split the oracle, keeper, and treasury roles onto separate addresses, then open proposals to token holders.

What the design commits to

  • Onchain and transparent. Proposals, votes, and execution all visible.
  • Snapshot-based voting, so voting power cannot be borrowed for a block.
  • Timelocked execution, once a timelock is actually deployed.
  • Progressive. Control moves outward as the pieces above land, and this page gets updated when they do.
